# MotoCaz

Projet web de gestion et de vente de voitures réalisé lors de mon stage d’initiation.

## Description

MotoCaz est une application web permettant la publication, la consultation et la gestion d’annonces de véhicules.  
Le projet comprend une interface utilisateur moderne ainsi qu’un espace d’administration pour gérer les utilisateurs, les clients et les annonces.

## Fonctionnalités

- Inscription et connexion des utilisateurs
- Consultation des annonces
- Publication d’annonces
- Gestion des annonces personnelles
- Tableau de bord client
- Tableau de bord administrateur
- Gestion des utilisateurs
- Gestion des clients
- Détail des annonces
- Interface super administrateur

## Technologies utilisées

### Frontend
